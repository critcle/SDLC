# Выбор связки React + TypeScript + Chart.js (HTML5 Canvas) для клиентской панели мониторинга

## Контекст и постановка задачи

Веб-панель управления **IoTPanel** должна непрерывно отображать в браузере оператора графики телеметрии (`temperature`, `motion`), поступающей от датчиков каждые 1–2 секунды (`BG-1`, `REQ-FUNC-002`), а также позволять в один клик переключать состояния устройств (`REQ-FUNC-005`) и конструировать правила через 4-шаговую форму (`REQ-FUNC-007`) без перезагрузки страницы. Какой стек клиентского приложения и библиотеку построения графиков выбрать, чтобы обеспечить плавную отрисовку живого потока данных без деградации памяти браузера?

## Драйверы решения

* **Производительность отрисовки (`REQ-PERF-001`):** задержка обновления графика после прихода пакета телеметрии не должна превышать 2 секунд даже при многочасовой сессии оператора.
* **Визуализация пороговых линий (`REQ-FUNC-012`, `SYS-08`):** необходимость отображения поверх графика горизонтальных пунктирных линий порога срабатывания правил (например, `28 °C`).
* **Надёжность типизации (`BG-3`):** строгий контроль типов при формировании JSON-объекта правила на клиенте.
* **Разделение труда в команде:** возможность параллельной вёрстки изолированных UI-компонентов силами привлекаемого Junior-разработчика.

## Рассмотренные варианты

* **Вариант 1:** Многостраничное серверное приложение (SSR) с простыми статическими SVG-графиками.
* **Вариант 2:** Одностраничное приложение (SPA) на React + TypeScript + SVG-библиотека графиков (`Recharts` / `D3.js`).
* **Вариант 3:** Одностраничное приложение (SPA) на React 18 + TypeScript + `Chart.js` (рендеринг на HTML5 Canvas).

## Итог решения

Выбранный вариант: **«Вариант 3: SPA на React 18 + TypeScript + Chart.js (HTML5 Canvas)»**, потому что аппаратно-ускоряемый рендеринг на едином элементе `<canvas>` гарантирует перерисовку скользящего окна телеметрии за `< 30 мс` без засорения DOM-дерева тысячами SVG-узлов и напрямую соответствует техническому заданию проекта.

### Последствия

* **Хорошо**, потому что `Chart.js` обеспечивает стабильные 60 FPS при потоковом обновлении данных по WebSocket и с большим запасом выполняет норматив `REQ-PERF-001` (`<= 2 с`).
* **Хорошо**, потому что компонентная модель React позволяет легко выделить вёрстку таблиц (`SYS-05`, `SYS-06`) и баннера тревоги (`SYS-10`) в отдельные файлы для Junior-разработчика.
* **Плохо**, потому что элементы внутри `<canvas>` нельзя стилизовать стандартными CSS-классами — настройка цветов и пороговых линий выполняется через конфигурационный объект JavaScript.

### Подтверждение

Соблюдение решения проверяется на этапе Code Review (контроль использования `react-chartjs-2` и строгого режима `tsc --noEmit`) и нагрузочным тестом интерфейса в браузере (отсутствие утечек памяти при приёме 1000 последовательных пакетов телеметрии).

## Плюсы и минусы вариантов

### Вариант 1: Многостраничное приложение (SSR) + статические графики

* **Хорошо**, потому что не требует сложной клиентской сборки.
* **Плохо**, потому что перезагрузка страницы сбивает состояние 4-шаговой формы правил и не позволяет обновлять графики в реальном времени.

### Вариант 2: React + TypeScript + Recharts (SVG)

* **Хорошо**, потому что SVG-элементы легко стилизуются через CSS.
* **Нейтрально**, потому что подходит для статических дашбордов с редким обновлением.
* **Плохо**, потому что при ежесекундном потоке телеметрии постоянная перестройка сотен DOM-узлов `<svg>` вызывает просадку производительности и рост потребления ОЗУ.

### Вариант 3: React 18 + TypeScript + Chart.js (HTML5 Canvas)

* **Хорошо**, потому что отрисовка выполняется на одном узле `<canvas>` с минимальной нагрузкой на CPU/GPU.
* **Хорошо**, потому что плагин `chartjs-plugin-annotation` из коробки рисует горизонтальные линии порогов правил (`SYS-08`).
* **Нейтрально**, потому что требует регистрации контроллеров и шкал `Chart.js` при инициализации модуля.

## Дополнительная информация

Связанные требования из SRS: `BG-1`, `REQ-FUNC-002`, `REQ-FUNC-012`, `REQ-PERF-001`. Элемент дизайна в SDD: `DV-01-Composition`, системные функции `SYS-02`, `SYS-08`.
